# 豆逗 · Android TV

豆逗 Android TV 正式版下载、更新说明与应用更新清单。最低支持 Android 6，支持遥控器操作。

## 下载安装

请从 [Releases](https://github.com/aston314/doudou-tv-releases/releases) 下载最新正式签名 APK。覆盖升级会保留账号和记录，安装仍需 Android 系统确认。

应用设置中的“检查更新”可以检查新版本。播放时不弹更新提示；确认更新后下载并核验文件完整性、应用版本与签名。

国内访问 GitHub 不稳定时，应用会尝试下载代理，失败后再尝试直连。

本仓库仅存放公开下载文件和版本说明，不包含应用源码、账号或凭据。
